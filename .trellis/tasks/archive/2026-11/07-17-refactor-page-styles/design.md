# 页面样式重构技术设计

## Scope and Boundaries

改造限定在 `web/src/` 的设计变量、共享 UI 组件、应用壳层和三个页面模板。现有响应式状态、API 调用、路由和业务函数保持不变；模板只围绕视觉层级、语义结构和操作区布局重组。

## Visual System

- 在 `style.css` 中重建亮色/暗色语义变量，沿用蓝紫主色，并以青色作为有限辅助色。
- 使用清晰的背景层、面板层、边界层和代码层，不依赖大面积渐变或装饰性卡片堆叠。
- 保留 Manrope 正文字体与 Syne 品牌字体；页面标题采用适合工具界面的紧凑字号，不使用超大营销式 Hero。
- 统一面板、状态提示、代码块、标签、字段说明和列表行的样式类，减少页面间重复 class 组合。
- 动画保持短促，并继续尊重 `prefers-reduced-motion`。

## Shared Components

- `AppShell.vue`：重组为桌面顶部控制台导航和紧凑移动导航，保留主题切换、当前路由高亮和 GitHub 入口。
- `PageHero.vue`：从居中营销式标题调整为紧凑页面上下文头部，可承载页面标识、标题、说明和附加操作。
- `Button.vue`、`Input.vue`、`Textarea.vue`、`Switch.vue`、`ThemeToggle.vue`：统一高度、圆角、焦点、禁用和交互反馈，保持现有 props 与事件契约。

## Page Layouts

- 首页：把链接生成器作为首要工作区，特性能力作为简洁状态标识，Docker 示例使用可扫描的命令面板。
- 离线镜像页：单镜像和批量下载形成纵向上下工作区。单镜像工作区采用紧凑横向表单，在窄屏回落为单列；批量工作区使用完整宽度，为镜像列表提供更大的编辑区域。两个工作区保持一致的标题、状态、选项和操作层级。
- 搜索页：搜索栏、结果元信息、结果列表、分页和标签详情形成一致的数据浏览工作区；长名称、描述和架构标签必须可收缩或换行。

## Compatibility and Accessibility

- 保留所有现有组件公开接口、路由和事件处理函数。
- 图标按钮继续提供 `aria-label`；原生 button、label 和 switch 语义不变。
- 焦点样式在亮暗主题下均可见；颜色不作为错误、成功或当前状态的唯一表达方式。
- 响应式断点沿用 Tailwind 默认断点，重点验证窄屏和常规桌面宽度。

## Rollback

改动按设计系统、共享组件、页面模板分组。若页面回归，可按文件回退对应页面模板；若全局视觉异常，可优先回退 `style.css` 与基础 UI 组件，不涉及数据迁移。
