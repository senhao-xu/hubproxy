# 重构页面样式

## Goal

为 HubProxy Web 前端建立更统一、清晰、现代的视觉系统，提升开发者在 GitHub 加速、离线镜像和镜像搜索三个核心流程中的扫描效率与操作体验，同时保持现有功能和路由行为不变。

## Confirmed Facts

- 前端使用 Vue 3、TypeScript、Tailwind CSS 4 和 Vite，入口位于 `web/src/`。
- 页面路由包括 `/`、`/images` 和 `/search`，分别对应 `HomePage.vue`、`ImagesPage.vue` 和 `SearchPage.vue`。
- 全局设计变量、基础层、动画和复用样式主要位于 `web/src/style.css`。
- 应用级导航、主题切换、移动端菜单位于 `web/src/components/AppShell.vue`。
- 页面标题与说明复用 `web/src/components/PageHero.vue`。
- 项目已有亮色/暗色主题、Manrope 与 Syne 字体，以及 `lucide-vue-next` 图标依赖。

## Requirements

- 采用“开发者控制台”视觉方向：突出工具属性、终端语义、清晰状态和适中的信息密度，避免通用营销页风格。
- 强化现有蓝紫品牌主色，并使用克制的青色辅助层次和独立语义状态色。
- 完整覆盖 `/`、`/images` 和 `/search` 三个页面，以及共享导航、页头和基础控件。
- 允许调整 Vue 模板结构与共享组件，以改善信息层级和响应式布局，但不得改变业务逻辑、路由或 API 合约。
- 统一三页的色彩、排版、间距、边框、控件和状态反馈表现。
- 优化桌面端和移动端的导航、页面头部、表单操作区、结果列表和下载表单布局。
- 离线下载页采用上下工作区：单镜像与批量下载同时可见，单镜像区保持紧凑，批量区获得完整宽度和更大的列表编辑空间。
- 保留现有业务交互：主题切换、移动端菜单、链接生成/复制/打开、镜像下载、搜索分页、标签筛选和复制拉取命令。
- 保留亮色与暗色主题，并确保两种主题下文字、边界、交互状态具有足够对比度。
- 使用现有 Vue/Tailwind/Lucide 技术栈，避免引入不必要的新 UI 依赖。
- 样式改动应限制在前端视觉与布局相关文件，不改变后端 API 合约。

## Out of Scope

- 修改链接生成、镜像下载、Docker Hub 搜索和标签加载的数据逻辑。
- 修改后端接口、路由地址或部署配置。
- 引入新的组件库、状态管理库或图标库。
- 新增业务功能或营销页面。

## Acceptance Criteria

- [x] 三个路由页面具有一致的视觉层级和可复用的页面结构。
- [ ] 桌面端与移动端在常见视口下无横向溢出、文字遮挡或控件错位。
- [x] 离线下载页两个工作区纵向排列，层级清晰，字段、选项、状态和操作按钮对齐一致。
- [ ] 所有现有核心操作仍可用，加载、成功、错误、禁用和空状态均有清晰样式。
- [ ] 亮色/暗色主题均能正常显示，导航当前项和表单焦点状态清晰可辨。
- [x] `npm run build` 在 `web/` 目录执行通过。
- [x] 视觉改造不新增 TypeScript 编译错误；浏览器运行时错误待人工控制台检查。
